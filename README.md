# BMS Widgets

تطبيق Android أصلي لويدجت سطح المكتب.

## V1.1
- تمديد ويدجت التاريخ أفقيًا وعموديًا مع بقاء حجم النص ثابتًا.
- التحكم بحجم الخط من 70% إلى 150%.
- التحكم بلون الخط.
- خلفيات: داكنة، شفافة، ليفر، النصر، السعودية.
- ويدجت جديد لمواقيت الصلاة في تبوك.
- إضافة الشروق إلى ويدجت الصلاة.
- الحساب يعمل دون إنترنت باستخدام إحداثيات تبوك وتقويم أم القرى في العرض الهجري.

## الويدجت المتاحة
1. التاريخ والوقت.
2. مواقيت الصلاة + الشروق.
