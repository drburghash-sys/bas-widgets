# BMS Widgets

نسخة 1.0: ويدجت أندرويد أصلي للتاريخ والوقت.

## ما يعرضه الويدجت
- اسم اليوم.
- التاريخ الميلادي.
- التاريخ الهجري وفق تقويم Umm al-Qura عبر ICU.
- الوقت بنظام الجهاز 12/24 ساعة.
- قابل لتغيير الحجم على سطح المكتب.
- الضغط على الويدجت يفتح تطبيق BMS Widgets.

## البناء
افتح المشروع في Android Studio (JDK 17) ثم Build > Build APK(s).

## إضافة الويدجت
1. ثبّت التطبيق.
2. افتح BMS Widgets واضغط «إضافة الويدجت»، أو اضغط مطولًا على سطح المكتب.
3. Widgets > BMS Widgets.
